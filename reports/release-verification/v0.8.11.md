# リリース確認レポート: v0.8.11

> 総合結果: **❌ 失敗あり**

v0.8.11 の確認中に失敗したステップがある。詳細は下記を参照。

このレポートは既存リリースと同じ flat layout の公開入口である。最終試行
`20260909T044300+0900-attempt5` は embedded smoke と SQL transaction
conformance を通過したが、mode-parity は gRPC proto 入力欠落と v0.8.4
catalog 互換性エラーで不完全終了した。すべての試行の不変原本は
[v0.8.11 evidence](v0.8.11/README.md) に保持する。
